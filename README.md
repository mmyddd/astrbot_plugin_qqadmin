# astrbot_plugin_qqadmin

_✨ QQ群管插件（官方 API 版，仅保留「清理群友」）✨_

基于 [QQ 机器人官方 API v2](https://bot.q.qq.com/wiki/develop/api-v2/) 实现的群管插件，适配 AstrBot 的 `qq_official` / `qq_official_webhook` 平台适配器。

## 📌 说明

- 插件只保留「清理群友」一个管理功能，其余群管指令已全部移除。
- 所有群操作都走官方 API，不再依赖 OneBot / aiocqhttp：

| 用途 | 官方接口 |
|------|----------|
| 获取群成员列表 | `GET /v2/groups/{group_openid}/members` |
| 获取群成员信息 | `GET /v2/groups/{group_openid}/members/{member_openid}` |
| 批量移除群成员 | `POST /v2/groups/{group_openid}/batch_remove_members` |

官方成员接口只返回 `member_openid`、`username`、`member_role`、`bot`、`joined_at`，
**没有「最后发言时间」和「群等级」**。因此「未发言天数」由插件监听群消息事件、在本地数据库记录每位群友的最后发言时间。

## ⌨️ 指令

| 指令 | 说明 |
|------|------|
| `群友信息` | 查看群成员（进群时间｜角色｜昵称） |
| `清理群友 <未发言天数>` | 列出超过该天数未发言、且为普通成员的群友 |
| `清理群友 <未发言天数> 确认` | 二次确认后批量移出群聊（每批 20 人，自动限速） |
| `群管配置` | 查看本群配置（可直接跟配置文本修改，例如 `未发言天数: 15`） |
| `群管重置` / `群管重置 all` | 重置本群 / 所有群的配置并清空活跃记录 |
| `群管帮助` | 查看指令帮助 |

清理时始终跳过群主、管理员与机器人账号，只处理普通成员。

## ⚙️ 配置

在插件配置面板中设置：

- **默认值配置 → 未发言天数阈值**：命令未指定天数时使用，默认 30 天，可在群内用 `群管配置` 单独修改。
- **未发言天数上限**：命令中可填写的最大天数，防止误传。
- **批量移除的每批人数**：官方接口单次最多移除 20 人。
- **指令权限管理**：官方 API 不提供群成员角色，只区分「超管」与「成员」。

## ⚠️ 注意事项

- 群成员列表、群成员批量移除属于官方开放平台的**内邀（白名单）能力**，未开通时接口会返回 `11253 应用无接口访问权限`，插件会给出对应提示，请在 QQ 开放平台申请开通。
- 机器人需为群管理员，接口才能移除成员。
- 本地活跃记录依赖机器人能收到群内消息；若机器人只接收 @ 消息，未 @ 机器人的发言不会被记录，这部分群友会在结果中标注为「无发言记录」并被跳过。
- 需要 AstrBot 的 QQ 官方机器人平台适配器（`qq_official` 或 `qq_official_webhook`）。
